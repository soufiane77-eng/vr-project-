## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/soufiane77-eng/vr-project-.git
```

Navigate into the project:

```bash
cd vr-project-
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build the project for production:

```bash
npm run build
```
